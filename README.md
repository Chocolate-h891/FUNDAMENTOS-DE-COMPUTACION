# Glosario de conceptos
## Fundamentos de computación 
Por Isabella Medina Molina 1A

---

### 1. Algoritmo: 
Es una serie de pasos ordenados para completar una tarea o alcanzar un objetivo.
Ejemplo: Un instructivo para armar un escrito.

---

### 2. Programa:
Es un conjunto de instrucciones escrito en un lenguaje de programación que puede entender y ejecutar una computadora.
Ejemplo: Un programa puede recibir tres calificaciones, calcular su promedio y mostrar si el estudiante aprobó o reprobó.

---

### 3.	Código fuente:
Es el conjunto de instrucciones que se escribe utilizando un lenguaje de programación, estas instrucciones representan la solución que se quiere ejecutar en una computadora.
Ejemplo: Escribir “Hola mundo”

---

### 4.	Lenguaje de programación:
Es un conjunto de reglas y símbolos que permite escribir instrucciones para que una computadora realice diferentes tareas.
Ejemplo: Python, Java y C++ son lenguajes de programación.

---

### 5.	Sintaxis:
Es el conjunto de reglas que indica cómo deben escribirse correctamente las instrucciones en un lenguaje de programación.
Ejemplo: Escribir una instrucción siguiendo el orden y las reglas que establece el lenguaje utilizado.

---

### 6.	Variable:
Es un espacio con un nombre que se utiliza para almacenar un dato y cuyo valor puede cambiar durante la ejecución de un programa.
Ejemplo:  Una variable llamada “edad” puede almacenar primero el valor 16 y después cambiar a 17.

---

### 7.	Constante:
Es un dato que tiene un valor fijo y que no cambia durante la ejecución de un programa.
Ejemplo: El valor de PI, utilizado en operaciones matemáticas.

---

### 8.  Tipo de dato:
Es la clasificación que se le da a la información que se utiliza en un programa.
Ejemplo: Un número entero, un número decimal, un texto o un valor verdadero o falso.

---

### 9.	Operador: 
Es un símbolo que permite realizar una operación con uno o varios datos.
Ejemplo: El símbolo “+” permite realizar una suma entre dos números.

---

### 10.	Expresión:  
Es una combinación de valores, variables y operadores que permite obtener un resultado.
Ejemplo: “5 + 3” es una expresión que da como resultado 8.

---

### 11.	Condicional: 
Es una estructura que permite tomar decisiones en un programa según se cumpla o no una condición.
Ejemplo: Si una calificación es mayor o igual a 6, mostrar "Aprobado"; de lo contrario, mostrar "Reprobado".

---

### 12.	Bucle:
Es una estructura que permite repetir una o varias instrucciones varias veces.
Ejemplo: Mostrar los números del 1 al 10 utilizando la misma instrucción de forma repetida.

---

### 13.	Función: 
Es un conjunto de instrucciones que se agrupan para realizar una tarea específica y que puede utilizarse varias veces dentro de un programa.
Ejemplo: Una función puede recibir dos números y calcular su suma.

---

### 14.	Parámetro: 
Es un dato que se coloca en la definición de una función para que pueda recibir información.
Ejemplo: En una función para saludar, `nombre` puede ser un parámetro que recibe el nombre de una persona.

---

### 15.	Argumento: 
Es el valor que se proporciona a una función cuando esta se utiliza.
Ejemplo: Si una función recibe un nombre, `"Ana"` es el argumento que se envía a la función.

---

### 16.	Retorno: 
Es el resultado que una función devuelve después de realizar una tarea.
Ejemplo: Una función que suma 4 y 6 puede retornar el resultado 10.

---

### 17.	Arreglo: 
Es una estructura que permite almacenar varios datos relacionados bajo un mismo nombre.
Ejemplo: Un arreglo puede almacenar las calificaciones de varios estudiantes.

---

### 18.	Objeto: 
Es una representación de algo dentro de un programa que contiene características y puede realizar determinadas acciones.
Ejemplo: Un objeto llamado `Estudiante` puede tener nombre, edad y calificaciones.

---

### 19.	Método: 
Es una acción o función que pertenece a un objeto y define lo que puede realizar.
Ejemplo: Un objeto `Estudiante` puede tener un método para calcular su promedio.

---

### 20.	Evento: 
Es una acción o situación que ocurre durante la ejecución de un programa y provoca una respuesta.
Ejemplo: Hacer clic en un botón puede provocar que el programa guarde información.

---
